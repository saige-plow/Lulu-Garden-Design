# Lulubug's Garden — Website Rebuild

Static HTML/CSS/JS prototype implementing the 05.22.26 feedback doc and the Huntsman Mental Health Foundation partnership requirements. No build step, no dependencies beyond two Google Fonts loaded via CDN link tags.

## Files

```
index.html                  Home
meet-garden-friends.html    Meet Garden Friends
about-us.html                About Us
join-now.html                Join Now
contact.html                 Contact
mental-health-matters.html   NEW — Mental Health Matters tab
press.html                   NEW — Press page
css/style.css                 Shared design system (brand colors, fonts, components)
js/main.js                    Mobile nav, newsletter popup, form loading states
```

## Running it in Replit

1. Create a new **HTML/CSS/JS** Repl (not Node — you don't need a server for this).
2. Upload all files above, keeping the `css/` and `js/` folder structure.
3. Set `index.html` as the entry file. Hit Run — Replit will serve it directly.

## Porting to WordPress / Cloudways

This was intentionally built with plain, semantic HTML and CSS classes (no framework) so it ports cleanly either way:

- **Elementor / Divi / page builder:** copy each section's text and swap in your builder's own layout widgets, using `css/style.css` as your color/font reference (hex values are documented at the top of the file). The nav, hero, character grid, and footer patterns each map to a builder section.
- **Custom theme / template files:** the HTML can be dropped into `header.php`, `footer.php`, and page templates almost as-is — the CSS classes don't depend on WordPress markup.
- **Forms:** on WordPress, recreate the Contact and Join Now forms with WPForms or Contact Form 7 using the same field names shown in the HTML (`name`, `email`, `subject`, `message`), and set the notification email per the routing note below.

## Brand system used

Pulled directly from `Lulubug Brand Guidelines Final (2).pdf`:

- **Colors:** Lulubug Red `#ED1C24`, Garden Vine `#7DB238`, Golden Nectar `#FFC421`, Morning Dew `#FFF5F2`, Evergreen Ivy `#386641`, Spring Seedling `#C9D480`, Apricot Petal `#FFBFB2`, Lulubug Blush `#FAA6AB`, Dragonfly Wing `#91CFE8`, Honeysuckle Glow `#F4D06F`.
- **Fonts:** Gluten (headlines) / Varela Round (body) — loaded from Google Fonts.
- **Tone:** warm, simple, calm — no clinical or "shouting" copy, per the guide's Tone & Voice page.
- **Mental Health Matters accent:** a distinct green (`--mh-green` in the CSS) separate from Garden Vine, per Huntsman's request for its own mental-health-awareness color.
